# Week 01 解答

依下列順序整合完成片段；所有路徑都相對於你自己的 package 根目錄。

## 整合順序

1. `src/mini_ml/greetings.py`：建立檔案並貼入 `fragments/01_greetings.py`。
2. `src/mini_ml/__init__.py`：建立檔案並貼入 `fragments/02___init__.py`。
3. `tests/test_greetings.py`：建立檔案並貼入 `fragments/03_test_greetings.py`。

對照當週 lesson.md，從 fragments/ 取用需要的解答。第一週解答示範 `hello_world()`、public API 與 unit test；`test_code/` 仍不提交。整合後跑截至本週測試，在原 PR 說明參考情況。

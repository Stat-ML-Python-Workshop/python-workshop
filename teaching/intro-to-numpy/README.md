# Intro to NumPy

Download `index.html` and open it in a browser. It is a standalone offline lesson with 16 slides, fixed teaching interactions, array examples and notes. Python code shown in the deck is for practice in your own environment; the browser does not execute Python.

Navigate with the arrows, Home/End or the slide menu. The last slide links to [kahoot.it](https://kahoot.it/) for the live quiz; your instructor provides the game PIN.

Reference: [NumPy absolute beginner guide](https://numpy.org/doc/stable/user/absolute_beginners.html). Small examples and diagrams are instructor-designed. Follow the [Week 5 lesson](../../weeks/week-05/lesson.md) for the assignment.
